Introduction

The Hotel Reservation System is a database-based application developed using Python and SQLite. It helps manage customer details, hotel rooms, room availability, and reservations.

Problem Statement

Manual hotel reservation management is time-consuming and may cause errors in customer records and room bookings. This project provides a computerized solution to manage hotel reservations efficiently.

Objectives

- Manage customer information.
- Maintain room details and availability.
- Create and manage reservations.
- Store and retrieve records using SQLite.
- Provide a simple graphical user interface.

Technologies Used

- Python
- Tkinter (GUI)
- SQLite (Database)
- Visual Studio Code

Database Tables

1. Customers
2. Rooms
3. Reservations

Features

- Customer Registration
- Room Availability Checking
- Room Reservation
- Reservation Records
- SQLite Database Storage
- User-friendly GUI

How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

python hotel_reservation.py

Conclusion

The Hotel Reservation System simplifies the management of customers, rooms, and reservations using Python and SQLite. It provides an easy and efficient way to store and retrieve hotel booking information.
